# Changelog

All notable changes to Tabryn will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-29

### Added

- Initial release
- MCP Server with 16 tools
- Chrome Extension (Manifest V3)
- Native Messaging Bridge
- CLI commands: install, mcp, doctor
- Tab management (list, select, create, close)
- Navigation (navigate, reload, wait)
- Page inspection (read_page, screenshot, execute_js)
- Interaction (click, type, scroll, form_input)
- Debugging (read_console, read_network)
- Typed protocol with version negotiation
- Cross-platform support (Windows, macOS, Linux)
